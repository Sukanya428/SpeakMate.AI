# SpeakMate.AI 🤖

An AI-powered English speaking coach designed to help users improve their communication skills through natural conversations.

## 🚧 Project Status

Currently under development.

The core AI conversation feature is implemented, and the project is being enhanced with additional features for a complete English learning experience.

## ✨ Current Features

✅ AI-based English conversation  
✅ Gemini API integration  
✅ Natural conversation with memory support  
✅ Grammar correction guidance  
✅ Vocabulary improvement suggestions  
✅ Simple and friendly English practice environment

## 🚀 How It Works

1. User enters a message in the chat interface.
2. Frontend sends the request to FastAPI backend.
3. Backend processes the message using Gemini AI.
4. AI generates a response and returns it to the user.
